ClaudeCode×Codex 連携マニュアル

制限がきたら、
もう片方で「続きから」。

Claude Code と Codex に、同じフォルダの「引き継ぎメモ」を読み書きさせます。片方が回数制限にかかっても、もう片方に「続きから」と送るだけで、同じ作業をそのまま続けられます。このページのURLを Claude Code に貼るだけで始まります。

所要時間 10分くらい 🍎 Mac / 🪟 Windows Claude（Pro・Max） ChatGPT（Plus 以上）

🚀 はじめ方 — URLを貼るだけ

  1. Claude Code で、いつも使っている作業フォルダを開く（Obsidian とつないだフォルダがあれば、そのフォルダ）
  2. 下の「コピー」を押して、このページのURLを Claude Code に貼り付けて送信
  3. あとは Claude Code の案内どおりに進めるだけ。最後に Codex で同じフォルダを開いて、テストします

04
使い方 — 覚えるのはこれだけ

  

    
交代するとき

    
もう片方のAIで同じフォルダを開いて、これを送るだけ。

    

  

  
⚠️2つのAIを同時に動かさない。同じファイルを同時に書き換えると、片方の作業が消えることがあります。片方が止まってから、もう片方を使ってください。

  
🧰スキルやコネクタ（Gmail・Chrome連携など）は共有されません。Claude Code で使えている道具でも、Codex で使いたいときは Codex 側にも入れる必要があります。

  
💡おすすめ：普段から役割を分ける。「文章・企画・設計は Claude Code」「できたものの見直し・2人目の意見は Codex」のように分けておくと、制限が片方に偏らず、交代もスムーズです。







  
05
困ったとき

  
基本は、エラーの文章やスクショをそのまま AI に貼れば、原因を調べて直してくれます。


  

    Codex が「続きから」に答えられない
    

      
Codex で同じフォルダを開いているか確かめてから、新しいスレッド（チャット）を始めて、もう一度「続きから」と送ってください。ルールはスレッドの最初に読まれます。

    

  


  

    引き継ぎメモが古いまま
    

      
「区切りごとに引き継ぎメモを更新して」と一言送ってください。直前の作業が途中で制限にかかった場合は、メモに書かれていない作業が少し残っていることがあります。「最後に何をしていたか、ファイルを見て確かめて」と頼むと、AIが続きを探してくれます。

    

  


  

    途中で止まってしまった
    

      
同じ作業フォルダを開いた Claude Code に、このページのURLをもう一度貼って「続きから」と送ってください。終わっているところは飛ばしてくれます。
